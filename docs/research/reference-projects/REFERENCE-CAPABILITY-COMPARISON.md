## Summary

- **Veyra differentiators:** strict invariants (Observe≠Store, Candidate≠Truth), repository truth wins, no silent authority changes, causal facet quality gates, transparent contradiction surfacing, read-only trust projection, explicit feedback with canonical protection, code-aware freshness via CBM.
- **dsh-engram strengths:** evidence-gated retrieval enforcement, merge reinforcement, distill/supersede chains, SM-2 spaced repetition, rich spatial/facts model, good budgets.
- **dsh-memory strengths:** active forgetting gate, strong auditability/protection, cognitive graph model, metacognition/prediction tools, MCP-centric design.
- **Others:** largely orthogonal (context compression, code intelligence, UI/marketplace).
